# Shadow Fiend — готовый монтаж

В этой папке находится версия ролика, подготовленная для скачивания через GitHub:

- `Shadow_Fiend_GitHub_720p.mp4` — готовое видео, 5:00, 1280×720, H.264/AAC;
- `Shadow_Fiend_ru.srt` — русские субтитры;
- `Shadow_Fiend_contact_sheet.jpg` — лист кадров для быстрой проверки монтажа.

Чтобы скачать ролик, откройте файл `Shadow_Fiend_GitHub_720p.mp4` и нажмите кнопку **Download raw file** (значок стрелки вниз справа вверху).

Исходный мастер 1920×1080 занимает около 177 МБ и превышает обычный лимит одного файла GitHub. Версия в этой папке сжата до размера, который GitHub принимает напрямую.
